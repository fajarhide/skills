# fajarhide/skills

Agent skills, published so they can be installed by name:

```sh
npx skills add fajarhide/skills
npx skills add fajarhide/skills --skill ui-receipts
```

| skill | what it is for |
| --- | --- |
| [`ui-receipts`](skills/ui-receipts/README.md) | Auditing the UI and UX of a web app in a real browser, where every finding carries a receipt, and proving a UI change before calling it done |
